# SmartScan Dataset & Benchmark Framework

This directory contains test images, ground truth annotations, and evaluation tools for the Smart Document Scanner.

## Directory Structure

```
dataset/
├── sample_images/          # Synthetic and benchmark document photographs
│   ├── doc_01_mild_angle_slate.jpg
│   ├── doc_02_moderate_angle_wood.jpg
│   └── ...
├── ground_truth/           # Mathematically verified ground truth corners
│   └── ground_truth.json
├── evaluation_results.csv  # Output results generated by evaluate_dataset.py
└── README.md
```

## Ground Truth JSON Schema

Each entry in `ground_truth.json` follows this format:

```json
{
  "doc_01_mild_angle_slate.jpg": {
    "id": "doc_01_mild_angle_slate",
    "filename": "doc_01_mild_angle_slate.jpg",
    "description": "Mild perspective tilt on slate background",
    "image_width": 1000,
    "image_height": 1000,
    "ground_truth_corners": [
      { "label": "TL", "x": 180.0, "y": 120.0 },
      { "label": "TR", "x": 820.0, "y": 140.0 },
      { "label": "BR", "x": 790.0, "y": 880.0 },
      { "label": "BL", "x": 150.0, "y": 850.0 }
    ]
  }
}
```

## Adding Real Photographs

To evaluate on real-world photographs:
1. Capture a photograph of a document against a contrasting desk or background.
2. Place the image in `dataset/sample_images/<your_filename>.jpg`.
3. (Optional) Measure or annotate the 4 corner pixel coordinates `(x, y)` in clockwise order starting from Top-Left: `[TL, TR, BR, BL]`.
4. Append an entry to `dataset/ground_truth/ground_truth.json`.
5. Run the evaluation script:
   ```bash
   python scripts/evaluate_dataset.py
   ```

## Dataset Generator Script

To regenerate synthetic test cases:
```bash
python scripts/generate_test_dataset.py
```
This programmatically generates perspective-warped documents on varied backgrounds (wood, slate, gradient, noise) with controlled lighting conditions.
